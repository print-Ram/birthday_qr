BIRTHDAY SURPRISE — READY-TO-UPLOAD WEBSITE

FILES
- index.html: the animated gift-opening birthday experience
- qr.html: makes a downloadable QR code for your live website address
- assets/birthday-photo.png: your supplied photo, copied without edits

HOW TO PUBLISH
1. Upload the complete contents of this folder to a static website host (for example, GitHub Pages, Netlify, or your existing web hosting).
2. Make sure index.html is at the site's root and keep the assets folder beside it.
3. Open https://YOUR-LIVE-SITE/qr.html
4. Enter the live homepage URL (https://YOUR-LIVE-SITE/) and press Create QR code.
5. Download the QR PNG, print it, and scan-test it using a different phone.

IMPORTANT
- A permanent, scannable QR cannot be finalized until the website has a public URL. The QR page included here generates it once you publish.
- The first tap on “Open your gift” starts the experience because mobile browsers block sound/autoplay until a user gesture.
- Voice uses the device/browser's built-in text-to-speech voice. The exact voice may vary by phone/browser and language settings.
- The QR generator loads QRCode.js from a CDN, so an internet connection is needed on qr.html when generating the QR.
- The uploaded photograph is used as-is; the site does not crop, retouch, or regenerate either face.
